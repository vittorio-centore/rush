Add a new exported server action `updateStageRelease` at the end of the file:

```typescript
export async function updateStageRelease(slug: string, stageId: string, formData: FormData) {
  const { supabase, club } = await requirePortalAdmin(slug);
  const isReleased = formData.get("is_released") === "true";

  const { error } = await supabase
    .from("club_pipeline_stages")
    .update({ is_released: isReleased })
    .eq("id", stageId)
    .eq("club_id", club.id);

  if (error) {
    redirect(buildRedirect(slug, undefined, error.message));
  }

  revalidateDecisionPaths(slug);
  redirect(buildRedirect(slug, "Stage visibility updated."));
}
```

This action uses `requirePortalAdmin` (admin-only), the existing `buildRedirect` helper, and `revalidateDecisionPaths` -- all already defined in this file. Only `is_released` is updated -- do NOT update `position` in this action (avoids Pitfall 6 unique constraint issue).
